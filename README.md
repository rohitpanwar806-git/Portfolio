# Rohit Panwar Portfolio

This portfolio website is a creative React + Three.js frontend built to showcase Rohit Panwar's Azure DevOps and Cloud Platform Engineering experience.

## Features
- 3D animated hero background powered by `@react-three/fiber`
- Clean enterprise portfolio layout with skills, experience, certifications, and contact details
- Responsive glassmorphism design inspired by modern creative portfolios
- Resume-driven content sourced from the uploaded Azure DevOps resume

## Development
Install dependencies and run the local dev server:

```bash
npm install
npm run dev
```

Build the production site:

```bash
npm run build
```

Preview the build locally:

```bash
npm run preview
```

## Notes
This repository is currently a portfolio shell created for Rohit Panwar. The site uses React, TypeScript, Three.js, and Vite.
